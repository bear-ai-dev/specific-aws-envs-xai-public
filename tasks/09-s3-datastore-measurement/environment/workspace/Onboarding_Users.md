# On Boarding Users

This document serves as a walk through to enabling user sign up with MeteringCo for the API and the Frontend

# API Sign up

For each Business unit we give them a single set of creds for access to our API. And we can onboard their users to the frontend app seperately

For API sign up simply create a Machine to Machine Application in the Auth0 dashboard:
https://example-tenant.auth0.com/dashboard/us/dev-joaofx7i/applications

Then assign it to the prod API.
